# 3지 TPU 소프트 그리퍼 + 단일 전극 멀티모달 센서 제어 시뮬레이션 — 설계 스펙

작성일: 2026-10-23 · 상태: 사용자 검토 대기

## 1. 목적과 성공 기준

**목적 (사용자 선택: C = 둘 다)**
1. 세미나/논문 데모 — Fig.1(b) 전체 파이프라인(센서 → TDM → 디커플링 → 멀티모달 정보 → 온보드 제어기 → 그리퍼)이 폐루프로 동작하는 모습을 3D 애니메이션과 그래프로 보여준다.
2. 제어기 설계 도구 — 실물 제작 전에 상태 전이 로직, admittance 게인, Material Lookup 값, Safety 임계값을 튜닝한다.

**성공 기준**
- 한 번의 파지 시퀀스에서 인장·근접·전기적 성질·접촉·압축(힘) 다섯 모달리티가 모두 신호와 그래프로 드러난다.
- 실제 배포된 v4 Gate-MoE(`stm32_deploy_moe_v4/models.pkl`)가 루프 안에서 디커플링을 수행한다.
- 시나리오 6종에서 목표 힘 추종·안전 동작이 정량 지표로 보고된다.
- 텐던/공압 두 구동 방식을 같은 제어기·시나리오로 비교한다.
- 도메인 시프트 + fine-tune 실험이 "시뮬레이션 내 방법론 시연"으로 명시되어 수행된다.
- 모든 모듈의 수식·개념을 다루는 A–Z 보고서(국문 docx)가 생성된다.

**비목표 (YAGNI)**
- MCU 펌웨어 타이밍의 사이클 단위 재현 (1 ms 주기 동기만 맞춘다)
- 연속체 FEM 소프트바디 (PRBM 힌지 체인으로 근사)
- 실물 그리퍼 성능 주장 (모든 수치는 시뮬레이션 결과로 명시)

## 2. 확정된 설계 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 물리 엔진 | MuJoCo 3D (`pip install mujoco`) | 3지 실제 3D 배치, 사용자 선택 |
| 소프트 손가락 모델 | 의사강체 모델(PRBM): 손가락당 힌지 4개 + 강성·감쇠 | 수식 보고서화 용이, 튜닝 단순 |
| 센서 모델 | 0909 실측 곡선/곡면 기반 순방향 모델 → TDM → 실제 v4 MoE | 디커플링 오차가 제어에 현실적으로 전파 |
| 센서 장착 | 손가락 안쪽면, 프리스트레치 ε₀=15% | 안쪽면은 굽힘 시 압축 → 학습 범위(인장 0–30%) 유지, 인장 모달리티 가시화 |
| 구동 | 텐던 + 공압 둘 다, 공통 명령 u∈[0,1] | 구동 방식 미정, 비교 목적 |
| 제어 | 게이트 기반 상태 머신: 위치(pre-shape) ↔ admittance 힘 제어 | 소프트 컴플라이언스에 순수 힘 제어 부적합 |
| 구현 언어 | Python 단일 프로세스, 다중 주기 | 단순·독립 테스트 가능 |

## 3. 아키텍처

```
[M0 MuJoCo 물리]  3지 그리퍼(PRBM) + 물체(재질·강성·크기·파손 태그) + 테이블
   │  관절각 q, 패드–물체 거리 d, 접촉 법선력 F, 접촉 이벤트
   ▼
[M1 센서 순방향]   (ε, d, F, 재질) → ΔL, ΔR, V
[M2 TDM 샘플러]    1 kHz, 노이즈·ZOH
[M3 v4 Gate-MoE]   SLS-EMA + gate + expert A/B → ε̂, d̂ | F̂, contact
[M4 재질 판별]     ΔL 잔차 부호 → 도체/유전체
[M5 제어기]        상태 머신 → pre-shape | admittance → Safety → u
[M6 액추에이터]    텐던 | 공압 → 관절 토크 τ
   └──→ M0 (폐루프)

[M7 도메인 시프트·fine-tune 실험]   [M8 로깅·시각화·보고서]
```

## 4. 모듈 수식

### M0 손가락 기구
- 손가락 L=80 mm, w=20 mm, t=6 mm, TPU 95A E≈26 MPa.
- EI = E·w·t³/12 ≈ 9.4×10⁻³ N·m², 힌지 강성 kⱼ = EI/ℓ_seg (ℓ_seg=20 mm) ≈ 0.47 N·m/rad, 감쇠 cⱼ = 2ζ√(kⱼ·Iⱼ), ζ≈0.3.
- M(q)q̈ + C(q,q̇) + Kq + Dq̇ = τ_act + Jᵀf_c (MuJoCo 적분).
- 3지: 원판 베이스에 120° 간격, 손바닥이 아래를 향함. 리프트용 수직 슬라이더 1축.

### M1 센서 순방향 모델 (0909 데이터 성분 분해)
- 안쪽면 변형률: ε = ε₀ − h·κ̄, κ̄ = Σ_{j∈센서구간} qⱼ / ℓ_sensor, h = t/2, [0, 30]%로 클립.
- ΔL = ΔL_ε(ε) + k_mat·ΔL_prox(ε, d) + ΔL_F(ε, F)
- ΔR = ΔR_ε(ε) + ΔR_F(ε, F)
  - ΔL_ε, ΔR_ε: proximity 24 mm 슬라이스(세션 214746).
  - ΔL_prox(ε,d) = S_L(ε,d) − S_L(ε,24): 근접–인장 곡면(214746+222022) 격자 보간. d>24 mm → 0.
  - ΔL_F, ΔR_F = S(ε,F) − S(ε,0): 압력–인장 곡면(220210 접촉 구간).
  - k_mat: 도체 1, 유전체 −0.1 (기존 그림과 같은 개략 가정).
- TENG: τ_T·V̇ + V = g_T·Ḟ (접촉 +, 분리 −). MoE 입력엔 미사용, 표시·이벤트용.

### M2 TDM 샘플러
- 1 kHz 샘플. 노이즈 σ_L, σ_R = 실측 정지 구간 표준편차. LDC 값 ZOH.

### M3 v4 Gate-MoE
- EMA: xₑ[k] = xₑ[k−1] + α(x[k] − xₑ[k−1]), α = 1 − exp(−ln2·Tₛ/T½), T½ = 0.70 s.
- gate: P(contact) = MLP_g(scaler_g(ΔL, ΔR)) ≥ 0.5, 상태 전이 시 EMA 리셋.
- expert A: [ε̂, d̂] = MLP_A(scaler_A(ΔL, ΔR, ΔLₑ, ΔRₑ)); expert B: [ε̂, F̂] = MLP_B(…).
- 검증: 실측 CSV(`moe_monitor_20260910_010437_test.csv`)를 재생해 보드 로그(strain_pct, value, mode)와 일치하는지 확인.

### M4 전기적 성질 판별
- r = ΔL − ΔL_ε(ε̂). 접근 단계에서 r < −θ → 도체, r > +θ → 유전체, |r| ≤ θ → 미정. 첫 접촉 순간 래치.

### M5 제어기 (손가락별 루프 + 전역 상태)
- 전역 상태: OPEN → APPROACH → GRASP → LIFT/HOLD → RELEASE. GRASP 진입: 3지 모두 contact 또는 타임아웃.
- Pre-shape: u_ref = u_open + (u_pre − u_open)·sat((d₀ − d̂)/(d₀ − d₁)), |u̇| ≤ u̇_max.
- Admittance: B_a·u̇ = F_t − F̂ → u[k+1] = u[k] + (Tₛ/B_a)(F_t − F̂[k]), 데드밴드 ±δF.
- Material Lookup: 도체 {F_t=4 N, F_max=8 N}, 유전체 {F_t=1.5 N, F_max=3 N}, 미정 → 유전체값(보수적).
- Safety(최우선): F̂ > F_max 또는 dF̂/dt > Ḟ_max 또는 ε̂ ∉ [0,30] → u를 개방 방향으로 램프.
- 게이트 전이 시 admittance 내부 상태 리셋.

### M6 액추에이터 (입력 u ∈ [0,1])
- 텐던: θ̇ₘ = sat((u·θ_max − θₘ)/τₘ, ±ω_max), τₘ = 20 ms; T = kₜ·max(0, r_p·θₘ − Σ rⱼqⱼ); τⱼ = rⱼ·T.
- 공압: Ṗ = sat((u·P_max − P)/τ_p, ±Ṗ_max), τ_p = 150 ms; τⱼ = αⱼ·P·(1 − β·qⱼ).

### M7 도메인 시프트 + fine-tune
- 장착 편향 주입: ε 오프셋 δε, 굽힘 결합 항 γ·κ̄ (ΔL에만), 감도 스케일 s.
- 시뮬 그리퍼 데이터 N개 수집 후 비교: ① 스케일러/선형 보정 ② fine-tune(warm_start, 작은 학습률) ③ 혼합 fine-tune(+0909 일부) ④ 처음부터 재학습.
- 출력: N 대비 회복 곡선, 평면 데이터 성능 유지(망각) 확인.
- 보고서에 "시뮬레이션 내 방법론 시연, 실물 근거 아님" 명시.

## 8. 나중에 확인할 항목 (사용자 체크리스트)

1. 손가락 실제 치수·TPU 경도(현재 L=80, w=20, t=6 mm, 95A는 가정값)
2. 센서 장착 위치(손가락 길이 방향 어느 구간)와 프리스트레치 ε₀=15%
3. 유전체 k_mat=−0.1 개략값 → D2 손 표적 실측 데이터로 대체할지
4. Material Lookup 힘 값(도체 4/8 N, 유전체 1.5/3 N)과 계란 파손 임계 3.5 N
5. 공압 파라미터(P_max, τ_p, α, β)
6. 물체 종류·크기 추가 여부
7. 리프트(중력) 포함 여부 — 현재 포함
8. 보고서 언어(국문만 vs 국·영문)
9. 도메인 시프트 주입 크기(δε, γ, s)
10. 그리퍼를 고정할지, 로봇 팔 끝에 달아 접근 동작까지 넣을지(현재 수직 슬라이더 1축)
