## 2. 플랜트 (A단계)

### 2.1 손가락 실물 사양 (모델이 따라야 할 것)
- 형상: `Hardware/pneunet_gripper` 기준. 손가락 105 × 30 mm, 공기 방 9개(블록 8 + 틈 2, 높이 20), 윗벽 2, 틈 쪽 벽 1.5, 옆벽 2, 등 R2.5.
- 손가락 2개를 마주 보게 배치한다. 허브 형상은 `hub_PLA`를 2지로 바꾼다.
- 재료: 몸체·바닥층 모두 **Dragon Skin 30**. 종이 같은 비신장층은 **없다**.
- 센서: EGaIn 채널을 DS30 안에 넣어 바닥층과 함께 주조한다. 강성이 바닥층과 거의 같으므로 모델에서는 바닥층의 일부(센서 위치의 변형률을 읽는 점들)로 둔다.
- 실측 기준점(사용자 예비 시험): **30 kPa에서 끝단 굽힘 약 300°**. 압력 범위는 0–30 kPa로 하고, ITV F_2 = 50 kPa, 지령 상한 30 kPa(현재 펌웨어 기본값)를 그대로 쓴다. 실물이 바뀌면 다시 잰다.

### 2.2 손가락 모델: 방이 부푸는 연속체 모델 (MuJoCo flex)
- 기존 `sim_gripper` 손가락은 강체 사슬(PRBM)이다. 이번에는 **MuJoCo 3.17 `flexcomp`(3차원 사면체 유한요소, 탄성 young/poisson)**로 손가락 몸체를 만든다.
  - 공기 방 내벽 삼각형 면마다 압력 하중 f = p·A·n을 매 스텝 정점에 나눠 건다(`xfrc_applied`/정점 힘).
  - 그러면 방이 부풀고, 등이 늘어나고, 바닥층이 굽는 현상이 모델 안에서 나온다. 별도 FEM 프로그램은 쓰지 않는다. MuJoCo flex가 곧 유한요소 모델이다.
- 사면체 메시는 `build_cad.py`의 몸체 형상(STEP/STL)에서 만든다(gmsh 또는 `flexcomp` 내장 메싱). 손가락당 정점 수는 안정성과 속도를 보고 정한다. 목표는 정점 1–3천 개다.
- **보정:** young 계수를 조정해 "30 kPa → 끝단 약 300°"를 맞춘다. 시작값은 DS30 카탈로그 경도 30A에서 환산한 약 1 MPa(가정)이다. poisson은 0.45–0.49로 둔다(비압축에 가깝게, 수치 안정성을 보고 정한다).
- **방 체적 V(p):** 부푼 방 내벽 메시에서 체적을 매 스텝 계산한다. 체적은 공압 동특성(2.3절)의 용량으로 들어간다.
- **센서 출력:** 바닥층 안 센서 위치 정점들의 길이 변화에서 변형률 ε을 계산한다. 비신장층이 없으므로 ε의 부호와 크기는 모델로 처음 확인한다(10절 위험 1).
- **대체안(위험 시):** flex가 300° 대변형에서 불안정하거나 실시간 대비 1/20보다 느리면 PRBM 사슬로 돌아간다.
  - 관절 토크–압력 관계와 방 체적 V(p)는 flex의 정적 결과로 보정한 표를 쓴다.
  - 방 부풂은 시각용 메시 크기로만 보인다.
  - 대체 여부는 첫 작업(스파이크 S0)에서 결정하고, 결정 기록에 남긴다.

### 2.3 공압 경로: ITV + 튜브 + 방
- **ITV** (`sim_gripper/actuators/pneumatic.py` 확장):
  - 1차 지연 τ_v, 순수 지연 θ_v
  - 데드밴드: 지령 < p_db(약 0.3 kPa, 사용자 관찰)면 출력 0. 처음 열릴 때 튐을 포함한다.
  - 분해능 1 kPa 계단: 정격 0.5 MPa × 감도 0.2 % F.S.
  - 포화 0–30 kPa, 압력 변화율 제한
  - 모니터 출력 p_mon = 출력 압력 + 잡음
- **튜브와 방:** 방 압력 p_c는 다음 식을 따른다.

      C(p_c)·ṗ_c = (p − p_c)/R_t,   C = dV/dp + V/(κ·p_abs)

  - R_t는 튜브 저항, κ는 비열비(1.4, 단열) 또는 1(등온)이다.
  - V와 dV/dp는 2.2절 flex에서 온다. 방이 부풀수록 용량이 커지고 응답이 느려진다. 이것이 부풂이 제어에 미치는 물리적 효과다.
- τ_v, θ_v, R_t 초깃값은 가정값이다. B단계 실측(7절 R2)으로 교체한다.

## 3. 신호 정의

| 기호 | 의미 | 측정 | 역할 |
|---|---|---|---|
| u | 압력 지령 [kPa] | – | 손가락당 제어 입력 1개 (손가락별로 같은 제어기) |
| p | ITV 출력 압력 | ITV 모니터 | 출력 y₁, 상태 |
| ε | 센서(바닥층) 변형률 | MoE ε̂ | **출력 y₂, 추종 대상** |
| ε̇ | 변형률 속도 | 관측기 추정 | 상태, 속도 제한 대상 |
| d, ḋ | 근접 거리와 접근 속도 | MoE d̂, 칼만으로 ḋ̂ | 상위 루프 기준값·속도 생성 |
| F | 접촉 힘 | MoE F̂ | 상위 루프 어드미턴스 입력, 내부 루프 외란 |
| 재질 | 도체 / 인체 / 유전체 | A: 정답 라벨 / B: 판별기 | 어드미턴스·속도 파라미터 선택 |

- 공칭 상태: x = [p, ε, ε̇]ᵀ(3차), y = [p, ε]ᵀ. 방 압력 p_c가 따로 보이면 4차로 늘린다.
- 최종 차수는 식별 결과(11.1절 차수 선택)로 정한다.
- 추종을 위해 적분 상태 x_I를 덧붙인다(11.3절).

## 4. 제어 구조

```
[상위 루프: 상태 머신, 100 Hz, 손가락마다]
  OPEN      : ε_ref = ε_open
  APPROACH  : ε_ref = g(d̂)  (근접 스케줄 pre-shape)
              속도 제한 |ε̇_ref| ≤ v_max(재질, d̂)
              접촉 예상 시간 t_c = d̂ / (−ḋ̂)가 짧으면 v_max를 더 낮춘다
  CONTACT   : 게이트 = 접촉 (B단계: ∨ TENG). 접촉 순간 ε_c 기록
  GRASP     : 어드미턴스  M_a·ε̈_ref + B_a·ε̇_ref = F_t − F̂   (|F_t − F̂| ≤ δF면 우변 0)
              (F_t, F_max, B_a, v_max) = 재질표[도체 | 인체 | 유전체]
  SAFETY    : F̂ > F_max 또는 ε > ε_max → ε_ref 감소. 인체면 F_max·v_max를 낮게 둔다
  RELEASE   : 사용자 명령 → ε_open으로 천천히 복귀
        │ ε_ref (속도 제한·기준 모델을 거친 매끄러운 기준)
        ▼
[내부 루프: 과제 2–6절, 100 Hz, 손가락마다]
  r = ε_ref → 적분기 → 상태 피드백 u = −K x̂ − K_I x_I (+ F r)
            → DOB 보정 u ← u − d̂_u → 포화 → ITV → 튜브·방 → 손가락(flex) → 센서·MoE → y = [p, ε̂]
  x̂ : 관측기(4절) 또는 칼만 필터(5절). 두 손가락은 같은 게인을 쓴다(대칭).
```

### 4.1 속도를 넣는 이유 (사용자 질문 5)
- **충돌 속도 = 접촉 순간 충격력:** 같은 F_t라도 손가락이 빠르게 닿으면 첫 순간 힘이 튀어 오른다(오버슈트). 접근 마지막 구간에서 ε̇를 줄여야 F_max를 지킨다.
- **인체:** 사람 손은 움직인다(ḋ ≠ 0). 이때 다음 규칙을 쓴다.
  - 손이 다가오면(ḋ < 0) 손가락은 더 느리게 닫는다.
  - 손이 멀어지면 pre-shape를 되돌린다.
  - 접촉 후에는 힘 증가율 dF/dt에 상한을 둔다. 안전과 불쾌감을 함께 막는다.
- **pre-grasp:**
  - 손가락이 물체보다 늦게 닫히면 물체를 밀어낸다. 반대로 너무 빠르면 미리 쳐버린다.
  - 그래서 t_c(접촉 예상 시간) 안에 목표 pre-shape에 닿도록 ε̇_ref를 정한다: ε̇_ref = (g(d̂) − ε)/max(t_c, t_min).
- **제어 이론과의 연결:** ε̇는 이미 내부 루프의 상태 x₃다.
  - LQR의 Q에서 ε̇ 가중을 키우면 같은 기준에도 느리고 매끄럽게 움직인다.
  - 기준값은 속도 제한기(또는 2차 기준 모델)를 거쳐 들어간다. 내부 루프가 포화되지 않게 하는 역할이다.
  - ḋ는 d̂를 상태 [d, ḋ]의 칼만 필터(등속 모델)로 추정한다. 5절 칼만의 두 번째 사용처다.

### 4.2 재질표 (초깃값, 모두 노란 칸)
기존 sim 값(판형 손가락용 4 N·1.5 N)은 PneuNet 힘 규모와 다르다. 그래서 **차단력 F_block**(30 kPa에서 손끝을 고정했을 때의 힘, 가상 실험 S8)에 대한 비율로 둔다.

| 재질 | F_t | F_max | B_a | v_max (ε̇) | 비고 |
|---|---|---|---|---|---|
| 도체 | 0.5 F_block | 0.8 F_block | 기준 | 기준 | 단단한 금속 물체 |
| 유전체 | 0.35 F_block | 0.6 F_block | 기준 × 1.5 | 기준 × 0.7 | 깨지기 쉬운 물체 가정 |
| 인체 | 0.15 F_block | 0.3 F_block | 기준 × 3 | 기준 × 0.4 | 안전 우선, dF/dt 상한 |

- 어드미턴스 B_a 기준값의 규칙: 힘 루프 시정수 τ_adm = B_a / k_env가 내부 루프 시정수의 3–5배가 되게 한다(캐스케이드 분리).
- k_env는 재질별 접촉 강성이다(S8, B단계 R6).

연속시간 식과 이산시간 식이 다르면 우리가 쓰는 **이산시간(Ts = 10 ms)**을 기준으로 쓰고, 강의의 연속시간 형태는 대응만 표시한다.

### 11.1 시스템 식별 (과제 2절)
- **질문:** 압력 지령 u를 넣으면 손가락 변형률 ε가 어떻게 따라오는가? 이 관계를 수식(전달함수)으로 얻는다. 이후 모든 설계가 이 식을 쓴다.
- **핵심 식 (ARX 모델과 최소제곱):**
  - 지금 출력을 과거 출력과 과거 입력의 가중합으로 쓴다:

        y(k) = −a₁y(k−1) − … − a_n y(k−n) + b₁u(k−1) + … + b_m u(k−m) + e(k)

  - 묶어 쓰면 y(k) = φ(k)ᵀθ + e(k)이다. 여기서 φ(k) = [−y(k−1) … u(k−m)]ᵀ, θ = [a₁ … b_m]ᵀ다.
  - N개 시점을 쌓으면 Y = Φθ + E이고, 오차 제곱합 ‖Y − Φθ‖²을 최소로 하는 해는 다음과 같다:

        θ̂ = (ΦᵀΦ)⁻¹ΦᵀY

  - 얻은 계수로 G(z) = (b₁z⁻¹ + … + b_m z⁻ᵐ)/(1 + a₁z⁻¹ + … + a_n z⁻ⁿ)을 만든다.
- **쉬운 설명:**
  - 데이터 점들에 가장 잘 맞는 직선을 긋는 것과 같다. 다만 "직선의 기울기" 대신 "과거 값들의 가중치"를 찾는다.
  - 오차 e가 서로 독립인 잡음이면 이 추정은 치우치지 않는다(Least Square 성질 i–iii).
  - 가진 신호는 PRBS나 처프를 쓴다. 손가락이 느린 움직임부터 빠른 움직임까지 다 보여줘야 계수를 정확히 구할 수 있기 때문이다.
- **차수 선택과 검증:**
  - 차수 (n, m)를 늘려가며 검증 데이터 적합도와 AIC를 비교한다:

        fit = 100·(1 − ‖y − ŷ‖/‖y − ȳ‖) %

  - 적합도가 거의 늘지 않는 최소 차수를 고른다(과적합 방지).
  - 식별용 데이터와 검증용 데이터는 다른 구간을 쓴다.
- **연속시간 변환:** ZOH 역변환으로 G(z)→G(s)를 얻는다. 극점은 z = e^{sTs} 관계다. 시정수와 고유진동수를 물리적으로 해석할 수 있다(예: ITV 시정수, 손가락 감쇠).
- **우리 시스템에서:**
  - 동작점 p₀(예: 15 kPa) 주변 ±3 kPa로 가진한다. 데드밴드(0.3 kPa) 근처를 피해 선형 근사가 성립하게 한다.
  - u→p와 u→ε를 둘 다 식별한다.
  - **한계:** 방 부풂으로 용량이 압력에 따라 변하므로 다른 동작점에서는 모델이 달라진다. 이 차이가 6절 DOB가 다룰 "모델 불확실성"이다.
- **출처:** P2_Lec3 Least Square p2–9(원리·추정기), p9–21(성질), p22–24(예제); P1_Lec2_2 Z변환; P1_Lec5 p24–41(이산 입출력 모델).

### 11.2 상태공간 모델과 해석 (과제 3절)
- **질문:** 전달함수를 "상태" 형태로 바꾸면 무엇을 알 수 있나? 이 시스템은 안정한가? 입력으로 모든 상태를 움직일 수 있나(가제어)? 센서로 모든 상태를 알아낼 수 있나(가관측)?
- **상태공간 실현:**
  - 연속시간: ẋ = Ax + Bu, y = Cx. 이산시간: x(k+1) = A_d x(k) + B_d u(k).
  - 물리 상태 x = [p, ε, ε̇]ᵀ로 쓰면 각 행렬의 뜻은 다음과 같다.
    - ITV: τ_v ṗ = −p + u
    - 손가락: ε̈ + 2ζω_n ε̇ + ω_n² ε = ω_n² K_f p

            A = [ −1/τ_v      0        0     ]   B = [1/τ_v]   C = [1 0 0]
                [   0         0        1     ]       [  0  ]       [0 1 0]
                [ ω_n²K_f   −ω_n²   −2ζω_n   ]       [  0  ]

  - 식별한 G(s)에서 바로 만든 가제어 정준형도 같은 시스템이다. 둘은 상사변환 x̄ = Q⁻¹x로 연결되고, 고유값과 전달함수는 변하지 않는다.
  - 물리 상태형을 쓰는 이유는 각 상태가 "압력, 변형률, 속도"라는 뜻을 가져서 Q 가중치나 제한을 정하기 쉽기 때문이다.
- **이산화 (ZOH):** 디지털 제어기는 Ts마다 u를 바꾸고 그 사이에는 값을 유지한다(영차 유지). 그러면 정확한 이산 모델은 다음과 같다:

      A_d = e^{A·Ts},   B_d = ∫₀^Ts e^{Aτ}dτ · B

  - Ts = 10 ms는 가장 빠른 극의 시정수보다 충분히 작게 고른다. 대략 대역폭의 10–20배 샘플링이다.
- **고유값과 안정성:**
  - 연속시간에서는 모든 고유값의 실수부가 0보다 작으면(Hurwitz) 안정하다.
  - 이산시간에서는 모든 고유값의 크기가 1보다 작으면(|z| < 1) 안정하다.
  - 개루프 손가락은 실리콘 감쇠 때문에 안정할 것으로 예상한다.
  - 고유벡터는 각 모드가 어떤 상태 조합으로 움직이는지 보여준다.
- **Lyapunov 방법:**
  - "에너지 같은 함수" V(x) = xᵀPx(P > 0)가 시간에 따라 계속 줄면 상태는 0으로 간다.
  - 이산시간 Lyapunov 방정식:

        A_dᵀ P A_d − P = −Q_L   (Q_L > 0 아무거나)

  - 이 식의 해 P가 양의 정부호이면 시스템은 점근 안정이다. 이것은 필요충분조건이다.
  - P의 양의 정부호 여부는 모든 고유값이 양수인지, 또는 선행 주소행렬식이 모두 양수인지로 확인한다.
  - 같은 식을 나중에 폐루프 A_d − B_dK에도 적용해 설계한 제어기의 안정성을 증명한다.
- **가제어성:** 가제어 행렬 𝒞 = [B_d, A_dB_d, A_d²B_d]의 랭크가 3이면, 압력 지령 하나로 세 상태를 원하는 곳으로 보낼 수 있다. 이것이 극배치의 전제 조건이다.
- **가관측성:** 가관측 행렬 𝒪 = [C; CA_d; CA_d²]의 랭크가 3이면, 출력 기록으로 모든 상태를 알아낼 수 있다. 이것이 관측기의 전제 조건이다.
  - **세 경우를 비교한다 (이 과제의 핵심 메시지):**
    - C = [1 0 0], 압력만 측정: ε는 p에 영향을 주지 않는다. 그래서 𝒪의 랭크가 1이고 손가락 상태가 **보이지 않는다**. ITV 모니터만으로는 굽힘을 되먹임할 수 없다.
    - C = [0 1 0], 센서 ε만 측정: p가 ε를 움직이므로 랭크 3이고 가관측이다. 다만 가관측 그래미안의 작은 특이값이 "p 추정이 잡음에 약함"을 보여준다.
    - C = [p; ε], 둘 다 측정: 가장 잘 조건화된다.
  - 결론: **우리가 만든 센서가 손가락 굽힘을 가관측하게 만든다.**
- **칼만 분해:** 랭크가 부족한 경우(예: 압력만 측정) 상태 공간을 "보이는 부분 / 안 보이는 부분"으로 나눈다. 안 보이는 부분이 스스로 안정하면(검출 가능, detectable) 관측기는 만들 수 있지만 그 부분의 추정 속도는 바꿀 수 없다.
- **출처:** Lec3_1(상태공간), Lec3_3 p19–33(TF→SS, 정준형)·p55–63(이산 실현), Lec4_2 p5–21(상사변환·대각화·고유값 해석), Lec4_1·4_3(해), Lec5 p17–24(ZOH, 이산 SS), Lec6_1 p23–36(LTI 안정성), Lec6_2 p27–39(Lyapunov 직접법), Lec6_3 p9–14(Lyapunov 방정식)·p74–(이산), Lec7_1 p19–22(가제어 행렬)·p59–60(그래미안)·p67–73(가관측 행렬), Lec7_2(연속시간), Lec7_3 p15–32(칼만 정준형, 안정화 가능·검출 가능).

### 11.3 상태 피드백 극배치 (과제 4절)
- **질문:** 상태를 다 안다면, 손가락 응답(속도, 오버슈트)을 내가 원하는 대로 만들 수 있나?
- **핵심 식:**
  - u(k) = −Kx(k) + F·r(k)이면 폐루프는 x(k+1) = (A_d − B_dK)x(k) + B_dF·r(k)가 된다.
  - K를 고르면 A_d − B_dK의 고유값(극)을 원하는 곳에 둘 수 있다. 가제어일 때만 가능하다.
  - Ackermann 공식: K = [0 0 1]𝒞⁻¹α_d(A_d). α_d는 원하는 특성다항식이다.
- **극 고르기:**
  - 원하는 감쇠비 ζ와 고유진동수 ω_n에서 연속극 s = −ζω_n ± jω_n√(1−ζ²)를 구한다.
  - 이것을 z = e^{sTs}로 옮긴다. 세 번째 극은 이보다 3–5배 빠르게 둔다.
  - 극을 너무 빠르게 하면 u가 커져 포화(30 kPa)되고, 1 kPa 계단 때문에 떨림이 생긴다.
- **정상상태 오차 없애기:**
  - F를 정적 이득의 역수로 고르면 공칭 모델에서는 오차가 0이지만, 모델이 틀리면 오차가 남는다.
  - 그래서 적분 상태 x_I(k+1) = x_I(k) + (r(k) − ε(k))를 덧붙여 4차 확대 시스템을 만든다:

        [x; x_I](k+1) = [A_d 0; −C_ε 1][x; x_I] + [B_d; 0]u + [0; 1]r

  - 확대 시스템에서 극배치하면 u = −Kx − K_I x_I이다. 일정한 하중이나 모델 오차가 있어도 ε가 r에 정확히 간다.
- **출처:** Lec8_1 p7–13(상태 피드백, 폐루프), p14(고유값 위치와 응답), p16–39(극배치, 가제어 정준형, 변환 Q, 알고리즘), p55–57(F 선택), p58–65(적분 동작, 확대 시스템).

### 11.4 관측기와 관측기 기반 피드백 (과제 4절)
- **질문:** ε̇처럼 측정하지 않는 상태는 어떻게 아나?
- **핵심 식 (선행 예측형 관측기):**

      x̂(k+1) = A_d x̂(k) + B_d u(k) + L(y(k) − C x̂(k))
      e(k+1) = (A_d − LC) e(k),   e = x − x̂

  - 모델로 예측하고, 실제 출력과의 차이에 L을 곱해 보정한다.
  - 가관측이면 A_d − LC의 극을 마음대로 둘 수 있다. 극배치와 쌍대 관계라 같은 Ackermann 공식에 Aᵀ, Cᵀ를 넣으면 된다.
  - 이후 사후형(측정 직후 보정)도 비교한다.
- **극 고르기:** 관측기 극은 제어기 극보다 2–5배 빠르게 둔다. 추정이 제어보다 먼저 수렴해야 한다. 너무 빠르면 센서 잡음이 x̂에 그대로 들어온다. 이 트레이드오프가 5절 칼만 필터의 동기다.
- **분리 원리:** u = −Kx̂로 바꿔도 폐루프 고유값은 {A_d − B_dK의 고유값} ∪ {A_d − LC의 고유값}이다. 그래서 K와 L을 따로 설계해도 된다.
- **우리 시스템에서:** y = [p, ε̂]로 ε̇를 추정한다. ε만 쓰는 경우와 비교해 11.2의 가관측성 결론을 결과로 보인다.
- **출처:** Lec8_2 p10–19(폐루프 관측기, 오차 동역학), p22–36(관측 정준형, L 계산 절차), p38–48(관측기 피드백, 분리 원리), p49–60(이산 사전·사후 관측기).

### 11.5 LQR (과제 4절)
- **질문:** 극을 "어디에" 둘지 감으로 정하는 대신, 성능과 입력 크기를 균형 있게 하는 최적의 K는 무엇인가?
- **핵심 식 (무한 시간 이산 LQR):**
  - 비용함수:

        J = Σ_{k=0}^{∞} [ x(k)ᵀQx(k) + u(k)ᵀRu(k) ]

  - J를 최소로 하는 제어는 u = −Kx이다:

        K = (R + B_dᵀPB_d)⁻¹B_dᵀPA_d
        P = A_dᵀPA_d − A_dᵀPB_d(R + B_dᵀPB_d)⁻¹B_dᵀPA_d + Q   (이산 대수 리카티 방정식, DARE)

  - 강의의 연속시간 형태는 0 = AᵀP + PA − PBR⁻¹BᵀP + Q, K = R⁻¹BᵀP이다(ARE).
  - 이산 형태는 동적 계획법(Bellman 방정식)으로 시간을 거꾸로 풀어서 얻는다: J_k(x) = min_u[xᵀQx + uᵀRu + J_{k+1}(x(k+1))]. 수렴하면 DARE가 된다.
- **쉬운 설명:**
  - Q는 "상태가 목표에서 벗어나는 것이 얼마나 싫은가", R은 "입력을 크게 쓰는 것이 얼마나 싫은가"이다.
  - Q를 키우면 빠르지만 입력이 커지고, R을 키우면 느리지만 부드럽다.
  - 극을 직접 고르지 않아도 이 균형에서 극이 자동으로 정해진다.
- **Q·R 근거 (Bryson 규칙):** Q_ii = 1/(x_i 허용 최대)², R = 1/(u 허용 최대)²에서 시작한다.
  - 예: ε 오차 허용 0.5 %, ε̇ 허용 v_max, 적분 상태는 정상상태 속도에 맞게, u는 30 kPa.
  - 이후 ε̇ 가중을 키워 매끄러움을 조절한다(4.1 속도와 연결).
- **성질:** 연속시간 단일 입력 LQR은 이득 여유 [0.5, ∞)와 위상 여유 ≥ 60°를 보장한다(귀환차 등식).
  - 이산시간에서는 이 보장이 그대로 성립하지 않는다. 그래서 설계한 K의 여유를 직접 계산해 보고한다.
- **비교 (결정론적 3종):** 극배치 / 관측기 기반 극배치 / LQR(관측기 포함)을 S5에서 비교한다. 지표는 상승시간, 오버슈트, 정착시간, RMSE, Σu², Σ|Δu|이다.
- **출처:** Lec9_1 p2–9(LQ 문제), p25–31(무한 시간 LQR), p32–37(ARE 풀이); Lec9_2 p13–19(최적 LQR), p20–27(귀환차), p28–36(이득·위상 여유), p37–39(Q·R 선택); P2_Lec1(동적 계획법, Bellman).

### 11.6 칼만 필터와 LQG (과제 5절)
- **질문:** 센서 잡음과 모델 오차가 있을 때 "가장 좋은" 상태 추정은 무엇인가?
- **잡음 모델:**

      x(k+1) = A_d x(k) + B_d u(k) + B_w w(k),   y(k) = C x(k) + v(k)

  - w(공정 잡음, 공분산 W)와 v(측정 잡음, 공분산 V)는 평균 0, 서로 독립인 정규분포다.
- **핵심 식 (강의 표기):** 매 스텝 두 단계를 반복한다.
  1. 측정 갱신 (필터링):

         x̂(k|k) = x̂(k|k−1) + M(k)Cᵀ[CM(k)Cᵀ + V]⁻¹ (y(k) − Cx̂(k|k−1))
         Z(k)   = M(k) − M(k)Cᵀ[CM(k)Cᵀ + V]⁻¹CM(k)

  2. 시간 갱신 (예측):

         x̂(k+1|k) = A_d x̂(k|k) + B_d u(k)
         M(k+1)   = A_d Z(k) A_dᵀ + B_w W B_wᵀ

  - M은 예측 오차 공분산, Z는 필터 오차 공분산이다.
  - 시간이 지나면 M이 일정해지고 이득도 상수가 된다(정상상태 칼만). 이 M은 LQR의 리카티 방정식과 같은 꼴(쌍대)을 푼 해다.
- **쉬운 설명:**
  - 칼만 필터는 "최적 L을 가진 관측기"다. 모델을 믿을지 측정을 믿을지를 잡음 크기로 자동 결정한다.
  - V가 크면(센서 잡음 큼) 측정을 덜 믿어 추정이 부드러워지고, W가 크면(모델이 부정확) 측정을 더 믿어 빠르지만 잡음이 섞인다.
  - 결과는 오차 제곱 평균을 최소로 하는 추정이다(조건부 기댓값).
- **값 정하기:**
  - V: S4 정지 잡음 실험에서 p와 ε̂의 분산을 잰다(측정값).
  - W: 식별 잔차와 파라미터 섭동 크기에서 시작해 조정한다. 조정 과정과 결과를 그래프로 남긴다.
  - W/V 비율을 바꿔가며 추정 RMSE와 잡음이 어떻게 변하는지 보인다(과제 요구 "공분산의 영향").
- **LQG:** LQR 이득 K와 칼만 추정 x̂(k|k)를 합친다(u = −Kx̂ − K_I x_I). 분리 원리로 따로 설계한다.
  - 주의: LQR 단독의 여유 보장이 LQG에서는 사라질 수 있다(Doyle, 1978). 그래서 6절 강건성 시험이 필요하다.
- **두 번째 사용처:** 근접 d̂로 [d, ḋ] 등속 모델 칼만을 돌려 접근 속도 ḋ̂를 얻는다(4.1).
- **출처:** P2_Lec2(확률 복습: 평균, 공분산, 정규분포, 조건부 기댓값), P2_Lec4 p2–8(문제 정의), p9–13(예측·필터링, k = 0 유도), 이후(재귀식, 정상상태). LQG 결합은 과제 PDF 5절.

### 11.7 외란 관측기 DOB (과제 6절, 강의 전: 기초부터)
- **질문:** 모델이 틀리거나(방 부풂, 강성 변화) 외부 힘(접촉, 하중)이 들어올 때, 그 영향을 추정해서 지워버릴 수 있나?
- **아이디어:**
  - 실제 플랜트 P를 "공칭 모델 P_n + 입력단 외란 d_u"로 본다: y = P_n(u + d_u).
  - d_u에는 외부 힘, 모델 오차, 데드밴드가 모두 들어간다.
  - 측정 y를 P_n의 역모델에 넣으면 "실제로 들어간 입력" u + d_u를 거꾸로 계산할 수 있다. 여기서 내가 넣은 u를 빼면 d_u가 남는다:

        d̂_u = Q(s)·[P_n⁻¹(s)·y − u],    u_실제 = u_제어기 − d̂_u

- **Q필터가 필요한 이유:**
  - P_n⁻¹은 미분기라 잡음을 키운다. 또 분자 차수가 분모보다 커서 그대로는 구현할 수 없다.
  - 그래서 저역통과 필터 Q(s) = 1/(τ_q s + 1)^r를 곱한다. r ≥ P_n의 상대 차수여야 QP_n⁻¹이 구현 가능하다.
  - 차단 주파수 ω_q = 1/τ_q보다 느린 외란·모델 오차는 지워지고, 빠른 성분(센서 잡음)은 통과시키지 않는다.
- **대역폭 트레이드오프:**
  - ω_q를 올리면 외란 제거가 빨라지지만 다음 문제가 생긴다.
    - 센서 잡음이 u로 많이 들어온다.
    - 입력이 커지고 1 kPa 계단과 부딪힌다.
    - 모델 오차·지연이 큰 고주파에서 불안정해질 수 있다.
  - 강건 안정 조건은 실제 P = P_n(1 + Δ)(Δ: 상대 모델 오차)일 때, 모든 주파수에서 |Q(jω)Δ(jω)| < 1이다. 그래서 ω_q는 모델 오차가 커지는 주파수보다 낮게 둔다.
  - 루프 지연(10 ms)과 ITV 지연은 P_n에 넣지 않고, u 경로에 같은 지연을 둬서 맞춘다.
- **구현:** Q와 QP_n⁻¹을 ZOH 또는 Tustin으로 이산화해 Ts마다 계산한다. 바깥 제어기(LQR 또는 LQG)는 그대로 두고 DOB만 덧붙인다.
- **우리 시스템에서:** 같은 조건(S6: 강성 ±30 %, τ_v ×2, R_t ×2, 하중, 접촉력 계단)에서 DOB 있음/없음과 ω_q 3개 이상을 비교한다. 지표는 회복 시간, RMSE, Σu², 잡음 영향이다.
- **출처:** 과제 PDF 6절. 강의에서 다루기 전이므로 관련 표준 문헌(외란 관측기 원 논문·교재) 1–2편을 인용한다. 인용은 확인한 것만 쓴다.

### 11.8 상위 루프: 근접·속도·어드미턴스 (연구 기여, 과제 1·7절 맥락)
- **근접 스케줄:** ε_ref = ε_open + (ε_pre − ε_open)·sat((d_far − d̂)/(d_far − d_near)). 물체가 가까울수록 미리 굽힌다.
- **속도:**
  - |ε̇_ref| ≤ v_max(재질, d̂)
  - 접촉 예상 시간 t_c = d̂/(−ḋ̂)를 쓴다. 식은 4.1절이다.
- **어드미턴스:** M_a·ε̈_ref + B_a·ε̇_ref = F_t − F̂.
  - 뜻: 힘이 모자라면 더 쥐고(ε_ref↑), 넘치면 푼다. 가상의 질량·댐퍼처럼 부드럽게 움직인다.
  - 이산화하면 ε_ref(k+1) = ε_ref(k) + (Ts/B_a)(F_t − F̂(k))이다(M_a = 0일 때, 기존 sim과 같은 꼴).
  - 접촉 강성 k_env(F ≈ k_env(ε − ε_c))를 넣으면 힘 루프는 시정수 B_a/k_env의 1차 시스템이 된다. 이 시정수를 내부 루프보다 3–5배 느리게 두는 것이 B_a 선택 규칙이다(캐스케이드 분리, 11.2의 고유값 분석을 그대로 쓴다).
- **재질별 차이:** 4.2 재질표. 인체에서는 안전 계층이 F_max·dF/dt를 최우선으로 지킨다.

## 12. 개정 (2026-11-20): 모드별 출력과 접촉 후 힘 직접 추종

사용자 결정 (2026-11-20): 입력은 손가락마다 하나씩(ITV 2개, u₁·u₂)이고, 접촉 후에는 F를 직접 추종하며 게인을 스케줄한다.

### 12.1 변수 (손가락 i)
- 입력: u_i는 ITV_i 압력 지령, 0–30 kPa.
- 상태: x_i = [p_i, ε_f,i]이고 두 모드에서 같다.
  - ε_f는 자유 변형률이다. 물체가 없을 때 손가락이 갔을 굽힘을 뜻한다.
  - A, B는 식별값을 그대로 쓴다.
- 출력:
  - 자유 모드: y = [p, ε], ε = ε_f.
  - 접촉 모드: y = [p, F, ε]이고 관계는 다음과 같다.
    - F = k_eq·(ε_f − ε_c)
    - ε = ε_c + g·(ε_f − ε_c), g = k_eq/k_env
- 적분 상태:
  - 자유 모드: Σ(ε_ref − ε̂). 접촉 모드: Σ(F_ref − F̂).
  - 모드를 바꾸는 순간 무충격 전환으로 x_I를 다시 초기화한다.
- 추정:
  - 칼만 측정값으로 접촉 중에는 ε̃_f = ε_c + F̂/k̂_eq를 쓴다. 이는 F̂를 ε_f의 측정으로 바꾼 것이다.
  - k̂_eq와 ε_c는 RLS로 추정한다 (P2 Lec3). 회귀식은 F̂ = k_eq·ε_f,m + c이고, ε_f,m은 측정 p로 돌린 개루프 모델이라 k_eq와 독립이다.
  - k̂_env = ΔF̂/Δε̂는 물체 식별의 보조 지표로 기록한다.
- 게인:
  - 접촉용 LQR은 C_F = [0, k_eq]로 적분을 확장한 뒤 k_eq 격자에서 미리 푼다. 실행 중에는 k̂_eq로 보간한다.
  - DOB는 같은 ARX(u → ε_f)에 ε̃_f를 넣어 쓴다.

### 12.2 S8 탐색 결과 (시뮬레이션, 근거)
- 물체 강성 k_obj를 강체에서 0.03 N/mm까지 바꿔도 k_eq는 0.47–0.50 N/%로 거의 같다. 소프트 손가락이 직렬 강성을 지배하기 때문이다.
- 접촉 위치와 물체 크기를 바꾸면 k_eq가 0.28–0.52 N/%로 약 2배 변한다.
- 따라서 게인 스케줄의 대상은 재질이 아니라 '어디를, 어떤 크기로 쥐었는가'다.
- k̂_env로 재질의 무르기를 판별하는 것도 접촉 위치 효과에 섞인다. 이는 한계로 보고한다.

### 12.3 실험 추가·변경
- S8: k_eq·k_env 측정 (재질 3종 + 위치·크기 6종), 접촉 중 F̂ 잡음 V_F.
- S9 (신규): 힘 유지 비교. 고정 물체 4종에 대해 다음 4가지 제어기를 비교한다.
  1. 기존 어드미턴스 → ε 루프
  2. F-LQG (공칭 k_eq)
  3. F-LQG + RLS 스케줄
  4. 3번 + DOB
  - 지표: 유지 RMSE, 정상 오차, 계단 오버슈트, Σ|Δu|.
- S7: 새 제어기로 영상을 다시 만든다.
- 해석: 모드별 가관측성. 접촉 중 ε만 측정하면 σ_min이 g²에 비례해 줄어드는 반면, F̂를 측정하면 k_eq²에 비례한다.

### 12.4 가정
- 접촉 중에도 τ_f가 같다고 둔다. F 관계는 준정적 선형이다.
- 두 손가락이 물체를 통해 묶이는 결합은 외란으로 보고 DOB가 맡는다.
- 무른 물체는 스프링 패드로 만든다. 값은 가정이다: 유전체 2.0 N/mm, 인체 0.7 N/mm.

## 13. 개정 (2026-11-23): 상·하위 제어기 계층과 시나리오 2개

- **상위 제어기 (PC)**: 시나리오 관리, 재질 식별, 상태 머신, 기준(ε_ref | F_ref, F_t, F_max) 생성. 주기 20 Hz, UART 지연 20 ms (가정값).
- **하위 제어기 (STM32G473 + TDM 보드)**: TDM 1 kHz → MoE → 반사 안전(F̂ > F_max 3 ms 연속 → ITV 배기 래치, F̂ < F_t 20 ms → 해제), 내부 루프 100 Hz (LQG / F-LQG + RLS). 반사 문턱은 상위가 재질로 정해 내려보낸다. 반사 상태는 상위에 플래그로 올리고, 감독기는 SAFETY로 간다.
- **시나리오 1 (도체)**: 탐지 → 식별 → 접근 → 접촉 → 파지 → 유지. 결과는 S7을 쓴다.
- **시나리오 2 (인체)**: 탐지 → 식별 → 접근 → 접촉 → 상호작용. 상호작용은 (a) 안전 + 약한 힘 유지(C)와 (b) 어드미턴스 따라가기를 비교한다 (S11: 손 ±6 mm, 0.25 Hz).
- **S10**: 하위 반사의 이점을 보인다.
  - 고장 주입: 파지 유지 중 손가락 B 지령이 30 kPa로 폭주. 인체·도체 각각.
  - 비교: 상위 SAFETY 배기(지연 20/100/200 ms, 통신 두절) vs 하위 반사(두절 포함). 지표는 F_max 초과 충격량과 최대 F.
  - 보조: 손 급이동(0.1 s에 10 mm)으로 SAFETY 동작을 ε 열기와 배기로 비교한다.
- **식별의 한계**: 시뮬에서 인체는 도체 센서 모델을 쓰므로 도체·인체를 구별하는 신호가 없다. 재질은 정답 라벨을 쓴다 (B단계 R1).
