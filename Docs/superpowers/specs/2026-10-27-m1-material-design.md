# M1 물체 구별(유전체·재질) 모달리티 — 설계 스펙

- 작성: 2026-10-27 · 상태: 사용자 검토 대기
- 상위 문서: `Docs/plan/연구계획.md` 4절 M1, 7절 G-E2·G-F3·G-E9
- 일정: 10/28 – 11/23 (실측은 줄이지 않는 항목)

## 1. 목적과 주장

논문 주장 C1의 "재질" 모달리티를 정량 근거로 세운다.

> 단일 2선 전극의 (ΔL, ΔR, V_TENG)만으로 접근 물체가 도체인지 유전체인지 판별하고,
> 접촉 순간에는 유효 유전율 ε_eff와 마찰대전 극성을 추정해 **학습하지 않은 물체도 물리 범주로 분류**한다.

비목표: 재질 이름 맞히기(닫힌 집합 분류), PCB 변경(다중 주파수는 13절 향후 과제).

## 2. 물리 근거와 난점 (세미나 S12 기준)

| 자극 | f | ΔL/L₀ (겉보기) | 비고 |
|---|---|---|---|
| 인장 30 % | ↓ | 약 +20 % | R도 ↑ |
| 도체 근접 0 mm | ↑ | 약 −20 % | 와전류 |
| 유전체 근접 0 mm | ↓ | 약 +2 % | 기생 용량 C↑ — L 변화가 아니라 C 변화가 f에 섞인 것 |
| 접촉 | — | — | TENG 전압 |

1. 유전체 신호는 도체의 약 1/10이고 10 mm 밖에서는 거의 0이다.
2. 유전체 근접과 인장이 같은 방향(f↓)이다 → ΔR로 ε̂를 구하고 잔차 `r = ΔL − ΔL_ε(ε̂)`로 분리한다.
3. r은 거리와 재질이 섞인 값이다 → **TENG 접촉 시점(d = 0)에서 r을 읽어** 거리 미지수를 없앤다.

## 3. 출력 정의 (두 수준)

| 수준 | 언제 | 출력 | 방법 |
|---|---|---|---|
| L1 | 상시 (접근 중) | 도체 / 유전체 / 없음 | r 부호 + 지속 시간 (시뮬 `MaterialClassifier`와 같은 규칙) |
| L2 | 접촉 순간 | ε_eff (연속값), TENG 극성, 범주(도체 / 저εr / 중εr / 고εr), unknown | r_contact와 TENG 특징으로 회귀 + 범주 구간 + 거리 기반 미지 판정 |

범주 경계 (초기값, D1 결과로 조정): 저εr < 3.5 ≤ 중εr < 15 ≤ 고εr.

## 5. 실험 프로토콜

공통: 기존 인장 시험기 Z축 접근, 0909와 같은 펌웨어·로깅. 시행 전후 10 s 기준선. 시행마다 온도·습도 기록.

| 실험 | 조건 | 반복 | 산출 |
|---|---|---|---|
| D1 정적 특성 | ε = 0, 학습 시편 + 보조 변수 + 홀더, 거리 30 → 0 → 30 mm 연속, 1 mm/s | 3 | 재질별 r(d) 곡선, 접근·후퇴 히스테리시스 |
| D2 인장 결합 | ε = 0 / 10 / 20 / 30 %, 도체·아크릴·유리·물 백, 거리 연속 | 3 | 교차항, **인장 중 감지 가능 거리** |
| D3 접촉 + TENG | 학습 시편 전부, 접촉 후 0 → 5 N, 접근 속도 2단계 (1, 5 mm/s) | 10 | r_contact, TENG 극성·피크, 힘 증가 시 r 변화. M2(G-E3) 데이터 겸용 |
| D4 블라인드 | 미지 시편 포함 무작위 재질 × 무작위 ε (0–20 %), 접근 → 접촉 | 약 50 | 온라인 L1·L2 혼동행렬 |

거리 정답: M0 레이저 센서가 준비되면 레이저, 아니면 `Z_mm` + 오프셋(시편 두께 보정).

## 6. 데이터 형식·위치

- 폴더: `Data/M1_material/YYYYMMDD_<실험>/` + `README.txt` (시편, 치수, 온습도, 특이사항)
- 파일명: `<실험>_<시편>_eps<변형률>_rep<n>.csv`
- 열: 기존 `moe_monitor` 열 + **`ldc_raw`(28-bit 원시 f)**, `teng_raw`, `specimen`, `rep`.
  기존 로그는 `dL_pct`만 있어 기준선 재계산이 불가하므로 원시 f 열 추가가 필요하다 (로깅 스크립트 수정, 펌웨어 변경 없음).

## 7. 분석

1. 기준선·드리프트 보정 (시행 전후 기준선 선형 보간).
2. ε̂: 기존 ΔR → ε 곡선(0909)으로 역산. D2에서 ε̂ 오차 → r 오차 전파를 측정.
3. 잔차 r = ΔL − ΔL_ε(ε̂), 홀더 기여분 차감.
4. D1: 재질별 r(d) = A_mat · g(d) 모양 공유 여부 검정 (공유하면 재질 = 진폭 하나).
5. 감지 가능 거리: r(d)가 잡음·ε̂ 오차 3σ를 넘는 최대 d, (재질 × ε) 지도.
6. D3: TENG 상승 에지에서 r_contact, 극성, 피크 추출. 힘에 따른 r 변화(압축 효과)로 읽는 시점 창 결정.

## 8. 모델

- ε_eff 회귀: 입력 (r_contact, ε̂, 접근 속도 무관 특징) → log ε_eff. 1차 후보는 단조 보간(물리 곡선), 2차 후보는 소형 MLP. 단순한 쪽이 기준을 만족하면 그것을 쓴다.
- 범주: ε_eff 구간 + TENG 극성.
- unknown: 학습 특징 분포와의 마할라노비스 거리 > 임계 → "unknown".
- 온보드: 기존 MoE 뒤 단계로 추가, 접촉 이벤트에서만 실행. 목표 추가 시간 < 20 µs, 메모리 < 1 KB.

## 12. 위험과 대응

| 위험 | 대응 |
|---|---|
| 유전체 신호가 잡음·드리프트에 묻힘 | 기준선 보정, 평균 창 확대, 감지 거리 축소를 결과로 보고 |
| 인장 중 ε̂ 오차가 r을 덮음 | "인장 중 감지 가능 거리"를 한계로 정량 보고, 접촉 시점 읽기는 영향 작음 |
| 접지·면적 의존이 커서 ε_eff가 흔들림 | 보조 변수로 정량화, "유효 유전율"로 명시 |
| TENG가 특정 재질에서 약함 | 극성 대신 r만으로 범주, TENG는 접촉 시점 표지로만 사용 |
| 레이저 미준비 | Z축 + 오프셋, 오차 범위 명시 |

## 13. 향후 확장 (범위 밖): 다중 주파수 측정

탱크 커패시터가 다른 두 공진 주파수로 같은 코일을 측정하면 `1/(2πf)² = L(C_tank + C_par)` 두 식으로 L과 C_par를 분리할 수 있다. 이것으로 거리와 무관한 재질 지표, 강자성/비자성 도체 구분, 손실(젖은·생체 물질) 구분이 가능해질 수 있다. M1 결과를 본 뒤 2027 PCB 개정에서 검토한다.
