## 1. 연구 한 장 요약

**제목(가):** Embedded AI-Driven Single-Electrode Soft Multimodal Sensor for Perception and Adaptive Control in Soft Robotics

```
[센서]  EGaIn 단일 전극 스파이럴 (2선) — 인장·압축·도체/유전체 근접·접촉
[측정]  스위칭 PCB + 1 ms TDM → L, R_DC, V_TENG
[해석]  SLS-EMA + Gate-MoE (≈1.4 k 파라미터, STM32 260 µs) → ε, d | F, 접촉
        + 재질(ΔL 잔차 부호) + TENG 접촉 융합            ← M1·M2 (11월)
[제어]  상태 머신 · 근접 스케줄 pre-shape · 재질 적응 admittance · 안전 계층   ← 시뮬 완료
[응용]  3지 소프트 그리퍼 (실물)                           ← 2027.1월~
```

**논문 핵심 주장:**

| ID | 주장 | 근거 상태 |
|---|---|---|
| C1 | 단일 2선 전극에서 다섯 모달리티(인장·근접·힘·접촉·재질) | 인장·근접·힘 ✅ / 재질·접촉 정량 ⬜ (M1·M2) |
| C2 | 1 ms TDM 측정 회로·펌웨어로 L·R·V 시분할 | ✅ (TDM 특성 정량은 초록 이후) |
| C3 | 1.4 k 파라미터 Gate-MoE의 MCU 실시간 디커플링, 해석적 역산보다 안정 | 오프라인 ✅ / 실시간 성능 🔄 (M0) / 선정 근거 ⬜ (M3) |
| C4 | 모달리티를 쓰는 소프트 그리퍼 제어 구조 | 시뮬 ✅ / 실물 2027 |

**논문 서사 틀 (11/02, FlexiRay 검토 반영 — 10절):**
- **사람 촉각 분류로 시작한다.** 사람 손의 촉각 7가지(압력·접촉 위치·질감·온도·고유수용감각·진동·통증) 중 무엇을 하는지 표시하고, **사람에게 없는 감각(접촉 전 근접, 전기적 재질)**을 더한다.

| 사람 촉각 / 추가 감각 | 본 연구 | FlexiRay (Nat. Commun. 2026) |
|---|---|---|
| 압력(힘) | ✅ F̂ (접촉 전문가) | ✅ |
| 고유수용감각(자기 변형) | ✅ ε̂ (R 주도) | ✅ (노드 위치) |
| 접촉 이벤트 | ✅ TENG + 게이트 | (힘으로 간접) |
| 접촉 위치 · 질감 · 온도 | ✗ (단일 코일 — 어레이·다중 주파수는 향후) | ✅ |
| 진동 | ❓ TENG 동적 응답으로 가능성만 (M2에서 확인 전에는 주장 안 함) | ✗ |
| **접촉 전 근접** (사람에게 없음) | ✅ d̂ | ✗ |
| **전기적 재질** (사람에게 없음) | 🔄 도체/유전체 (M1) | ✗ |

- **"한계를 기능으로" 서사.** FlexiRay는 변형이 시야를 가리는 문제를 거울 배열로 기능화했다. 우리는 **한 코일에서 신호가 섞이는 문제(L이 ε와 d에 동시 의존)**를 TDM + 디커플링으로 다섯 모달리티의 원천으로 바꾼다.
- **숫자 대비:** 카메라·GPU 기반 25.8 ms (30 fps) ↔ 2선 코일·MCU 1 ms 주기, 추론 260 µs. 접촉 후에만 감지 ↔ 접촉 전부터 연속 감지.

**일정이 밀리면 줄이는 순서:**
1. 통합 과제 영상(G-E18)과 크기 추정(G-E17)은 본 논문으로 미룬다.
2. FEA는 경향 비교만 한다.
3. 비접촉 조종 데모(G-E15)는 본 논문으로 미룬다.
4. 내구성은 1,000회 간이로 줄이고, 10,000회는 본 논문에서 한다.
5. 실시간 재검증이 늦으면 M0 원인 분석 결과로 대체한다.

M1(재질)·M2(TENG) 실측은 줄이지 않는다.

**시뮬·분석 중 발견한 실물 시사점:**
- **그리퍼 장착 시 v4 성능 저하:** 평면 시험 데이터로 학습한 v4는 그리퍼 조건(접촉 중 굽힘과 힘이 동시에 변함)에서 크게 떨어진다. 실물 그리퍼에서도 장착 상태 보정 데이터가 필요할 것이다.
- **v4 게이트의 유전체 접촉 미검출:** v4 게이트는 도체 압자 데이터로만 학습해서 유전체 접촉을 거의 못 잡는다. 펌웨어에 TENG 융합 접촉 판정이 필요하다.
- **프리스트레치 상한:** 압력 학습 데이터는 접촉 시 변형률 14 % 이상 구간을 제외했다. 그래서 프리스트레치는 14 % 미만을 권장한다.
- **벨로즈 손가락의 센서 위치:** 안쪽면이 중립축이라 인장 모달리티가 거의 없다. 인장을 쓰려면 굽힘면 장착이나 2채널 구성을 검토해야 한다.
- **인장 피드백 제어의 센서 요구사항:** 시뮬에서 인장 내부 루프는 ε̂ 오차 ~0.4 %(이상 센서)에서 동작하고, 보정 MoE의 ~1.6 %에서는 성능이 떨어졌다. 디커플링 정확도가 제어 구조 선택을 정한다는 근거로 쓸 수 있다.
- **TENG 래치 해제:** 펌웨어에서도 분리 펄스 크기가 아니라 누적 전하(적분)로 해제해야 가벼운 접촉·튕김에서 래치가 남지 않는다. 실측 TENG의 누설·드리프트 확인 필요 (M2).
- **들어 올릴 때 안전 계층 오작동:** 금속 파지 실패의 대부분은 리프트 중 실제 힘 상승(Ḟ > 50 N/s)에 Ḟ 안전 조건이 걸려 손가락을 연 경우다. HOLD 중 Ḟ 트립은 "열기"가 아니라 "유지"가 맞다 (수정 검토 중).
- **판형 손가락의 물체 강성 추정 불가:** 손가락 자체 컴플라이언스가 지배해 인장–힘 기울기로 금속·계란·스펀지를 구분할 수 없다 (1.0 / 0.9 / 0.8 N/%).

## 8. 소통 방식

1. **주 1회 세 줄 체크인:** "한 일 / 막힌 것 / 이번 주 가능한 실험"을 보내면, Claude가 5절(이번 주 할 일)과 3절(일정)을 갱신한다.
2. **요청 형식:** "목표 · 마감 · 완료 기준 · 데이터 위치" 한 줄.
3. **실험 데이터 넘기기:** 날짜 폴더에 원데이터를 넣고 `README.txt`에 한두 줄 메모를 남긴다. Claude가 분석 → 그림 → 7절 상태 → 논문 스케치까지 갱신한다.
4. **결정 기록:** 범위·방향을 바꾸는 결정은 6절 결정 기록에 남긴다.
5. **월말 점검:** 밀린 항목은 3절의 "줄이는 순서"대로 명시적으로 줄인다.

### 9-2. 이 표가 바꾸는 주장 (중요)

1. **"인덕티브 소프트 센서는 L/R 두 모달리티까지, 대형 계측 장비 필요"는 그대로 쓸 수 없다.** Peng 2024가 2선 코일과 두 주파수로 굽힘·힘을 분리했다. → 우리 차이: 모달리티 수(5 vs 2), 근접·접촉·재질, **인장** 상태, 단층 구조(페라이트·전도막 없음), MCU 단독.
2. **"단일 소자 다중 모달 + 로봇 폐루프"도 단독 차별점이 아니다.** He 2026이 단일 정전용량 단위로 압력·온도·근접 + 로봇 손 폐루프를 막 발표했다. → 우리 차이: 센서가 **스스로 늘어나는 상태**에서의 디커플링(인장이 측정량), 도체/유전체 재질, 어레이 없이 한 소자.
3. **"MCU 온보드 추론"만으로는 약하다.** 유연 센서용 MLP를 STM32에서 돌린 사례가 있다. → 우리 주장은 "5 모달리티 디커플링을 1 ms TDM 주기 안에서 MCU 단독으로"로 좁힌다.
4. **사람/금속 구분은 선례가 있다** (Yim 2023, 강체 피부). → 우리는 인장 중 잔차 기반 + 접촉 시점 ε_eff 추정으로, 신축 센서에서 학습하지 않은 물체까지 범주화한다 (M1).
5. **"소프트 그리퍼 + 다섯 모달리티"는 FlexiRay가 이미 Nat. Commun.에 냈다.** 모달리티 수로는 차별화가 안 된다. → 우리 차이:
   - 접촉 **전**부터 감지 (근접, 재질)
   - 1 ms 주기·MCU 단독 (카메라·GPU 없음)
   - 2선 얇은 패치라서 다른 소프트 구조에 붙일 수 있음
   - 우리가 못 하는 것(접촉 위치·질감·온도)은 Discussion에서 인정한다.

### 9-3. 남는 조합 (포지셔닝 문장)

검색 범위 안에서 아래 네 가지를 **동시에** 만족하는 연구는 찾지 못했다.
① 신축 센서 자신의 인장을 측정량으로 다루면서, ② 접촉 전 근접 → 접촉 → 힘까지 연속 인지하고, ③ 도체/유전체 재질을 구분하며, ④ 2선 단일 소자에서 MCU 단독으로 실시간 디커플링한다.

- 필요성 문장: 소프트 로봇 피부는 스스로 변형하고, 그 자기 변형이 근접·접촉·재질 신호를 오염시킨다 (같은 문제의식: 공압 스트레인 게이지의 자기 변형/외부 접촉 분리, 정전용량 e-skin의 신장/압입 분리 연구).
- 한 줄 논지 (A): *A single two-wire stretchable coil that perceives approach, contact, force, strain and material, and decouples them on a microcontroller while the coil itself deforms.*
- 그림 아이디어 (G-F1 후보): 인장된 센서가 근접 물체를 만났을 때 — ΔL만 쓴 추정(오판) vs 본 연구(정답). 기존 해석적 역산 발산 결과(시뮬 F7)와 연결.
