멀티모달 연성 센서 평가를 위한
3축 정밀 측정 시스템의 설계 및 제작

문희준 · 학번 2026020607 고려대학교 기계공학과 BioRC Lab 정밀공학특론 · 2026-1학기 제출일 2026. 06. 17.

1 연구 배경 및 제작 동기

본 연구에서 제작한 것은 멀티모달 연성 센서(EGaIn 단일 전극 스파이럴 코일)의 인장 변형률(ε)·근접 거리(d) 동시 응답을 정밀하게 평가하기 위한 3축 자동화 정밀 측정 시스템이다. 시스템의 구조 부품과 센서 지그는 Fusion 360 CAD 설계 → FDM 3D 프린팅으로 제작하였다.

제작이 필요한 이유는 연성 센서의 응답이 ε과 d 두 변수에 동시 의존하기 때문에, 두 변수를 독립적으로 제어하면서 수만 개의 동기화 데이터를 수집하려면 마이크로미터 수준의 반복 위치 정밀도와 자동화된 스윕 기능이 반드시 필요하다. 상용 인장 시험기는 근접 거리 제어 기능이 없고, 범용 스테이지는 소프트 센서용 맞춤 클램프를 장착할 수 없다는 한계가 있다.

2 기존 방식의 한계 (Before)

핵심 문제: 수동 지그(손 클램프)로 연성 센서를 신장하면 위치 반복 오차가 ±2 mm 이상이다. 1 mm 간격으로 37개 변형률 조건을 재현해야 하는 본 연구에서는 이 오차가 치명적이다. 또한 근접 물체를 50 mm에서 0 mm까지 자동으로 스윕할 방법이 없어, 두 변수(ε, d)의 조합 데이터를 체계적으로 수집하는 것이 불가능하다.

2.1 수동 방식의 한계

  • 위치 반복 정밀도: 손 조임 클램프 ±2 mm → 설계값 대비 100~660배 오차
  • 소프트 샘플 손상: 범용 금속 클램프가 PDMS 기판 표면 손상
  • 근접 축 부재: 상용 인장 시험기에는 Z축(근접 거리 제어) 없음
  • 데이터 비동기: 센서 데이터와 위치를 수동으로 맞춰야 함 → 오차 수백 ms

2.2 기존 설비의 비용·구조 문제

  • 상용 인장 시험기: 가격 수천만 원, 단축(1D) 신장만 지원
  • 범용 XYZ 스테이지: 맞춤 센서 마운트 장착 불가, 배선 공간 없음
  • 데이터 수집 소프트웨어: 별도 NI DAQ 등 추가 비용 발생
  • → 맞춤 3D 프린팅 + 오픈소스 제어로 자체 제작이 최선
Fig. 1. (a) 수동 지그 vs 자동화 스테이지 핵심 성능 비교: 위치 반복 정밀도 ±2 mm → ±3 µm (약 670배 개선), 제어 가능 변형률 조건 수 비정형 → 37개, 데이터 동기화 수동 → 하드웨어 자동 동기, 근접 제어 불가 → 자동 스윕. (b) 자동화 스테이지로 수집된 데이터셋의 ε–d 2D 분포 (N=28,433개): 37개 변형률 조건과 0–50 mm 근접 거리 연속 스윕이 체계적으로 커버됨 — 수동 방식으로는 불가능한 분포.

3 디지털 제조 공정 (Fabrication Process)

선택 기법: Fusion 360 CAD 설계 + FDM 3D 프린팅
선택 이유: ① 소프트 센서 전용 무손상 클램프 형상은 상용품 없음 → 맞춤 설계 필수, ② 설계 반복 주기가 짧아야 하므로(인터페이스 수정 수회) 3D 프린팅이 금형 대비 압도적으로 유리, ③ Fusion 360의 파라미터 모델링으로 치수 공차 0.2 mm 반영 후 G-code 자동 생성 가능.
Fig. 2. 3D 프린팅 기반 정밀 측정 시스템 제조 공정 흐름. ① Fusion 360으로 센서 클램프·레일·마운트 설계 (공차 0.2 mm 반영) → ② FDM 프린팅 (구조부 PLA 40% 인필 / 센서 접촉부 TPU 20%) → ③ 볼 스크류·스테핑 모터 장착·조립 (320 steps/mm, 1/8 마이크로스텝) → ④ Arduino + Python GUI 연동 (ABS/JOG 프로토콜, STM32 하드웨어 동기). 하단 좌: 3D 프린팅 부품 목록 (5종). 하단 우: 완성 시스템 주요 사양.

3.1 Fusion 360 설계 핵심 사항

센서 게이지 길이(120 mm)를 기준 치수로 삼아 클램프 간격·볼 스크류 행정(0–36 mm)·Z축 근접 레일(0–50 mm)을 파라미터로 정의하였다. 소프트 PDMS 기판이 손상되지 않도록 접촉면에는 TPU 인서트를 설계하고, 조립 허용 공차를 0.2 mm로 설정하였다. 완성된 CAD 모델에서 3D 도면과 BOM이 자동으로 생성되어 논문·보고서 삽화로 활용하였다.

3.2 FDM 설정 및 소재 선택

부품 유형소재레이어 두께인필선택 이유

3.3 소프트웨어 제어 구성

Arduino Uno(AccelStepper 라이브러리)가 5개 축 스테핑 모터를 가감속 제어하고, Python GUI(PyQt5 + pyserial)에서 ABS/JOG 명령을 전송한다. STM32G473CBT6(센서 계측 MCU)와 UART로 하드웨어 동기하여 위치와 센서 데이터를 1 ms 이내 오차로 대응시킨다. 이 소프트웨어-하드웨어 통합 구성이 수동 방식 대비 가장 큰 Before/After 차이를 만드는 부분이다.

4 결과 (After)

완성된 3D 프린팅 기반 정밀 측정 시스템을 사용하여, 37개 변형률 조건(0–36 mm, 1 mm 간격)에서 근접 거리 50→0 mm 연속 스윕 실험을 수행하였다. 총 28,433개의 동기화 데이터를 수집하고(train/val/test 분리), 2단 AI 디커플링 모델(978 파라미터 MLP)로 학습·검증하였다.

Fig. 3. 정밀 측정 시스템으로 수집한 데이터 기반 AI 검증 결과. (a) 변형률 추정: MAE = 0.348 % (테스트셋, N=5,018개). (b) 근접 거리 추정: MAE = 1.868 mm. (c) Before/After 핵심 지표: 위치 정밀도 670배 향상, 데이터셋 37조건 체계 수집, HW 동기 달성, AI 학습 가능 수준의 데이터 품질 확보.

5 한계 및 향후 계획

현재 한계

  • FDM 치수 오차: 프린팅 수축으로 실제 공차 ±0.2–0.3 mm → 정밀 조립 시 사상 필요
  • 1D 신장만 지원: 현재 X축 인장만 가능, 2D 변형(양축) 측정 불가
  • PLA 크리프: 장시간 하중 시 PLA 구조부 변형 → PETG·ABS 교체 검토
  • 근접 물체 각도: Z축 수직 접근만 가능, 비수직 근접 시나리오 미반영

개선 및 확장 계획

  • 2D 인장 지그 추가: Y축 클램프 설계(Fusion 360) → εx·εy 동시 제어
  • 소재 업그레이드: 구조 부품 PETG/Carbon-PLA 교체로 강성·치수 안정성 향상
  • 인라인 힘 센서: 로드셀 마운트 추가 설계 → 응력–변형률 곡선 동시 취득
  • SLA 프린팅 도입: 클램프 접촉면 표면 조도 개선 (Ra <1 µm 목표)
핵심 성과 요약: Fusion 360 CAD + FDM 3D 프린팅으로 맞춤 제작된 정밀 측정 시스템은 수동 지그 대비 위치 반복 정밀도를 약 670배 향상(±2 mm → ±3 µm)하였고, 이를 통해 수동으로는 불가능했던 체계적 ε–d 데이터셋(28,433개)을 수집하여 AI 디커플링 모델 학습 (MAE ε 0.348%, MAE d 1.868 mm)을 가능하게 하였다.
