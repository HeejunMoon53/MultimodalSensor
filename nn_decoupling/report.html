Physics-Informed Loss 함수

전체 Loss 구조

Ltotal = Ldata + λ · Lphys

Ldata = MSE(ε̂, ε) + MSE(d̂, d)

Lphys = MSE(ΔR_pred, ΔR_meas) + MSE(ΔL_pred, ΔL_meas)

ΔR_pred(ε̂) = α₁·ε̂ + α₂·ε̂²
ΔL_pred(ε̂,d̂) = β₁·ε̂ + β₂/(d̂+d₀)^k + β₃·ε̂·(1/(d̂+d₀)^k)

결론 및 시사점 (신규 실험)

  • Exp1 · 전체 데이터 PINN vs DNN: 전체 데이터에서 PINN이 근접거리 MAE 기준 -0.9% 개선. 충분한 데이터 조건에서는 격차가 작지만 물리 제약이 과적합을 억제합니다.
  • Exp2 · 데이터 효율성: 5파일(~10,000샘플) 수준에서 PINN이 DNN 대비 MAE d를 0.28mm 개선. 데이터가 부족할수록 Physics Loss의 regularization 이점이 두드러집니다. 새로운 센서 형상/재료 실험 시 데이터 수집 비용을 크게 줄일 수 있습니다.
  • Exp3 · Hold-out 보간: 비학습 구간(strain 10~20, 8.3%~16.7%)에서 PINN이 DNN보다 안정적. PINN의 성능 저하(±0.01mm)가 DNN(+0.06mm)보다 작아 물리 제약의 외삽 안정성이 확인됩니다.
  • Exp4 · 추론 시간: INT8 기준 2.1µs → TDM 1ms 주기의 0.2% 이하. 수식 역산(반복법, 수렴 불확실)과 달리 DNN은 O(1) 확정적 추론이라 실시간 임베디드에 완전히 적합합니다.

Exp 5 해석

  • 아키텍처 효과 (Two-Stage vs Single PINN): Two-Stage 구조가 Single PINN보다 d MAE ↓ 0.11mm. ΔR→ε̂ 독립 추정이라는 물리 인과관계를 구조에 hardcode한 결과, 네트워크가 더 적은 탐색 공간에서 올바른 해를 찾음.
  • Physics Loss 효과 (Single PINN vs Single DNN): 동일한 Single-Stage 아키텍처에서 λ=0.10 추가 시 d MAE ↑ 0.04mm. Physics Loss 단독으로도 regularization 효과가 있음.
  • 종합: 최고 성능은 Two-Stage × Physics Loss 조합. 구조적 inductive bias와 물리 제약이 상호보완적으로 작동함. STM32 배포 관점에서 818 params(Two-Stage) vs 626 params(Single) 차이는 Flash 사용량 ~0.8KB 차이로 무시 가능.
