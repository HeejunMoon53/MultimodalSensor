2. 데이터 입력 처리

원시 신호 → 입력 특징 변환

STM32에서 출력되는 raw 신호는 절대값이며 센서마다 초기값이 다름. 물리적으로 의미 있는 상대 변화율(%)로 변환하여 센서 개체차 제거.

ΔL/L₀ (%) = [ (L₀/L_meas)² - 1 ] × 100
ΔR/R₀ (%) = [ (R_meas - R₀) / R₀ ] × 100

L₀, R₀ : 기준 상태 (d=50mm, ε=0) 평균값

LDC IIR 필터 (α = 0.18)

L_filt[n] = (1-α)·L_filt[n-1] + α·L_raw[n]
α = 0.18 → τ ≈ 6 샘플 ≈ 0.1s @ 100Hz

LDC1614 공진 측정의 고주파 노이즈 제거. R_DC는 STM32 IIR(α=0.02) 적용된 Channel 2 사용.

3. Single-Stage vs Two-Stage 아키텍처 비교

Two-Stage 설계 근거

물리 방정식에서 ΔR은 ε에만 지배적으로 의존하고, ΔL은 ε와 d 모두에 의존:

R_theory(ε) = α₁·ε + α₂·ε² (d 독립)
L_theory(ε, d) = β₁·ε + β₂/(d+d₀)ᵏ + β₃·ε/(d+d₀)

Two-Stage는 이 인과구조를 아키텍처 자체에 hardcode: Stage1(ΔR→ε̂)은 ε만 담당, Stage2(ΔL,ε̂→d̂)는 d만 담당. Single-Stage는 ΔL, ΔR 모두를 동시에 보고 ε,d를 함께 추정 — 물리적 독립성을 데이터에서 학습해야 함.

4. Physics-Informed Neural Network (PINN)

4.1 PINN 개념 및 Loss 함수

순수 데이터 기반 DNN은 학습 데이터 분포 밖에서 물리적으로 불가능한 예측을 할 수 있음. PINN은 신경망 출력이 물리 방정식을 만족하도록 추가 패널티를 부과.

물리 모델 (경험적 피팅)

R_theory(ε̂) = α₁·ε̂ + α₂·ε̂²
L_theory(ε̂, d̂) = β₁·ε̂ + β₂/(d̂+d₀)ᵏ + β₃·ε̂/(d̂+d₀)

Loss 함수

L_total = L_data + λ · L_phys

L_data = MSE(ε̂_norm, ε_norm) + MSE(d̂_norm, d_norm)

L_phys = MSE(R_theory(ε̂), ΔR_meas)
+ MSE(L_theory(ε̂,d̂), ΔL_meas)

λ 워밍업 스케줄

epoch < warmup(50) : λ = 0.0
epoch ≥ warmup : λ = (ep-50)/(300-50) × 0.10

초기에는 데이터 손실만으로 빠르게 수렴 방향 설정 후, 물리 제약을 점진적으로 적용하여 학습 안정성과 물리 일관성을 동시 확보.

물리 파라미터 학습 방식

α₁, α₂, β₁, β₂, β₃는 unconstrained learnable parameters.
d₀, k는 softplus 적용으로 항상 양수 보장 (특이점 방지).

d₀ = softplus(d₀_raw), k = softplus(k_raw)

α₁·ε + α₂·ε² ≈ 저항-변형 관계. ε≈0.15(15mm)에서 ΔR/R₀ ≈ 7.5%.

물리 해석

  • α₁+α₂ 관계: 전체 저항 증가율이 이차 다항식으로 표현됨. R_DC의 변형 의존성 (도체 길이·단면적 변화)을 학습이 자동 포착.
  • β₂ 부호: β₂ < 0이면 d 감소 시 ΔL 감소 (상호 인덕턴스 부호). 물리적으로 타겟 물체 재질·형상에 의존하는 값.
  • d₀ = 0.52mm: 근접거리 0mm 근방 특이점 방지 오프셋. softplus로 항상 양수 보장.
  • k = 5.629: 거리-인덕턴스 감쇠 지수. 이론적으로 쌍극자 근사에서 k≈3이지만, 실제 형상에 맞게 학습됨.
